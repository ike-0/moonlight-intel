# Moonlight PC

This is a fork of of [Moonlight PC](https://github.com/moonlight-stream/moonlight-qt) project with my own take to add features I was missing.

It's targeting Linux Intel based clients (Thinkpads, Framework laptops). Do note this is mainly optimised for my setup, but is available for everyone to use.

Mainly focusing on:
 - Gnome (51.1)
 - Arch based distro

For transparency it is heavily assisted by Claude Code.

## Features (on top of original Moonlight app)
 - Auto HDR switching (Enables HDR in Gnome and rolls back once stream is over).
 - Multiple upscaler options
    - Lacanzos sharp
    - FSR1
    - NIS
